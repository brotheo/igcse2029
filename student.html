1 · Variables, constants, types, casting · 15 min

A name still stores a value. Python drops DECLARE and the arrow. A constant is the same idea, written in ALL CAPITALS. The type is the value, not a line that announces INTEGER.

Pseudocode you already wrote

CONSTANT TicketPrice ← 4.50
DECLARE seats : INTEGER
seats ← 30
DECLARE open : BOOLEAN
open ← TRUE

age ← INT(ageText)

Python 3.10 exam answer

TICKET_PRICE = 4.50
seats = 30
open = True

age = int(age_text)

No DECLARE, no arrow, no INTEGER or BOOLEAN. True and False start with a capital. Cast with int(), float() or str(). A constant is ALL CAPITALS, not the word CONSTANT.

2 · Input, output and sequence · 12 min

OUTPUT becomes print. INPUT becomes input, and it always comes back as text, even when the digits look like a number. Cast on the next line, then calculate. The lines still run once, from top to bottom.

Pseudocode

OUTPUT "Gate opens"
INPUT name
OUTPUT "Hello ", name
INPUT partyText
partySize ← INT(partyText)
OUTPUT partySize + partySize

Python 3.10

print("Gate opens")
name = input("Name: ")
print("Hello " + name)
party_text = input("Party size: ")
party_size = int(party_text)
print(party_size + party_size)

If the input is added before int(), "3" + "3" is the text 33, not 6. Print the result after the calculation, not before.

3 · Selection: if, elif, else · 18 min

The decision is the one you can already trace. Python uses a colon and four spaces instead of THEN and ENDIF. When only one band should run, the later tests are elif, not a new if.

Pseudocode

IF mark >= 80 THEN
    OUTPUT "A"
ELSE
    IF mark >= 50 THEN
        OUTPUT "P"
    ELSE
        OUTPUT "U"
    ENDIF
ENDIF

Python 3.10

if mark >= 80:
    print("A")
elif mark >= 50:
    print("P")
else:
    print("U")

A second if starts a new test, so two messages can print. elif means only one band. Check the highest band first. No THEN, no ENDIF.

4 · Selection: match-case · 12 min

This is the new piece. match is not CASE OF copied across. Name the value once. Each case is an exact value. case _ is the leftover, and it is last. A range such as 80 or more stays an if.

Older CASE shape

CASE OF day_code
    "M" : OUTPUT "Museum"
    "S" : OUTPUT "Sports hall"
    OTHERWISE OUTPUT "Ask at reception"
ENDCASE

Python 3.10

match day_code:
    case "M":
        print("Museum")
    case "S" | "L":
        print("Sports hall")
    case _:
        print("Ask at reception")

case _ is not OTHERWISE and not default. String labels need quotes. The | shares one branch. case >= 50 is not a case label.

Check · The code is not M, S or L. Which line must be last?
