Operator reference — what each sign means

Every example uses a = 17 and b = 5 — 17 people and 5 seats on a boat.

Arithmetic operators — they calculate

SignNameWhat it doesExampleResultUse it when the question says…
+AdditionAdds two valuesa + b22"total", "altogether", "add"
-SubtractionTakes the second value away from the firsta - b12"difference", "how many more", "change"
*MultiplicationMultiplies two valuesa * b85"each costs…", "times", "per person × people"

Worked examples · Selection

Part B · 0–10 minutes · read each one, predict the output, then check

Selection lets a program choose what to do. The condition after if or elif is a relational or logical expression — the operators from Part A.

Example 1 · if / elif / else: ferry fares

# Ferry fare by age
age = 70
if age < 5:
    fare = 0
elif age < 18:
    fare = 20
elif age >= 65:
    fare = 15
else:
    fare = 35
print(fare)
Output15

Python checks the conditions from the top and runs only the first branch that is True, then skips the rest. else catches everything left — here, ages 18 to 64.

age317184065
fare020353515

Example 2 · Nested decisions: who may board

# A decision inside a decision
has_ticket = True
age = 14
with_adult = False
if has_ticket:
    if age >= 16 or with_adult:
        print("Board")
    else:
        print("Needs an adult")
else:
    print("Buy a ticket")
OutputNeeds an adult

The inner if only runs when the outer condition is True. Each level is indented four more spaces. Each else belongs to the if directly above it at the same indent.

Example 3 · Operators inside conditions: the last boat

SEATS = 12
queue = 30
left = queue % SEATS
if left == 0:
    print("All boats full")
elif left >= SEATS / 2:
    print("Send the last boat")
else:
    print("Wait for more people")
OutputSend the last boat

30 % 12 is 6, and 6 >= 6.0 is True. With queue = 36 the output is All boats full; with queue = 40 it is Wait for more people.

Example 4 · match-case: choosing a route

route = "B"
match route:
    case "A":
        print("Koh Samui")
    case "B":
        print("Koh Phangan")
    case "C":
        print("Koh Tao")
    case _:
        print("Unknown route")
OutputKoh Phangan

match compares one value against each case in turn. case _ is the default — like else, it matches anything not matched above, so always put it last.

Example 5 · One case, several values

day = "Sat"
match day:
    case "Sat" | "Sun":
        surcharge = 10
    case "Mon" | "Tue" | "Wed" | "Thu" | "Fri":
        surcharge = 0
    case _:
        surcharge = -1
print(surcharge)
Output10

Inside a case, | means "or this value". It is only used in case patterns — in an if condition you still write the word or.

if / elif or match-case?

Use if / elif / else when…Use match-case when…
you test ranges: age < 18, score >= 50you compare one variable with exact values: "A", "B", "C"
you combine different variables with and / oryou are building a menu or choosing from codes
you need a decision inside a decision (nesting)several values lead to the same action (|)

range reference

Part C · 0–5 minutes · cover the "Visits" column and say each one aloud

Use for with range when you know how many times to repeat before the loop starts. The loop variable takes each value in turn; the indented lines run once for each value. Use while instead when you stop because a condition becomes false.

FormExampleVisitsRule
range(stop)range(5)0 1 2 3 4Starts at 0. Stops before 5.
range(start, stop)range(1, 6)1 2 3 4 5Start included. Stop not included.
range(start, stop, step)range(0, 8, 2)0 2 4 6The step is how much the counter grows each pass.
start = stoprange(5, 5)nothingThe start is not before the stop, so the body never runs.

The pattern for a total:

# Add the numbers 1 to 5
total = 0
for count in range(1, 6):
    total = total + count
print(total)
Output15
  • Want 1 to 5 inclusive? The stop is 6 — one past the last number you need.
  • total = 0 goes before the for line.
  • The final print sits at the left edge, after the loop — or it prints on every pass.
  • The for line ends with a colon, and the body is indented four spaces.
  • Do not add 1 to the counter yourself. range already moves it — changing it inside the loop does not change the next value.
