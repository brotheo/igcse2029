Lesson: Count-controlled loops — for and range (improved)

15 core steps · syllabus 8.1.5(c) · teach this before Part C

Lesson plan

The full lesson for this week, with the review fixes applied. Every code block and output has been run in Python 3. Click a step to open it.

01Intro — Repeat a count you already know

A museum prints seat numbers 1 to 5 before the doors open. The count is known before the loop starts, so this is a count-controlled loop. In Python that is for together with range.

# Print the seat numbers, then open the doors
for seat in range(1, 6):
    print(seat)
print("Doors open")

Output

1
2
3
4
5
Doors open

The loop variable seat takes each value in turn. The indented line runs once for each value. When the values run out, the next unindented line runs, which is why Doors open prints once, at the end.

Programming answers for exams from 2029 are Python 3.10 or higher. Use four-space indents, double quotes, and ALL CAPITALS for a constant. A comment sits on its own line. Do not write DECLARE, arrows, NEXT or ENDIF.

By the end you can:

  • write for with range(stop), range(start, stop) and range(start, stop, step)
  • say exactly which values a range visits, and remember that the stop value is never included
  • build a total with a loop and print it once
02Learn — range stops before the end value
You write Values visited Rule
range(5) 0, 1, 2, 3, 4 Starts at 0. Stops before 5.
range(1, 6) 1, 2, 3, 4, 5 The start is included. The stop is not.
range(0, 8, 2) 0, 2, 4, 6 The third number is the step.
range(5, 5) nothing The start is not before the stop, so the body never runs.

If you want the numbers 1 to 5 inclusive, the stop must be 6, one past the last number you need. Writing range(1, 5) drops the 5. That is the usual lost mark.

Quick check: which values does range(3, 7) visit? (3, 4, 5, 6)

03Worked example — Numbers 1 to 5, totalled

The loop adds each count into total. The print is outside the loop, so the total appears once.

# Add the numbers 1 to 5
total = 0
for count in range(1, 6):
    total = total + count
print(total)

Output

15

What this does: total starts at 0 before the loop. range(1, 6) visits 1, 2, 3, 4 and 5, and each pass adds the count: 1 + 2 + 3 + 4 + 5 = 15. The print is at the left edge, so it runs once, after the last pass.

04Learn — A step skips values

The step is the third value inside range. It is how much the counter grows after each pass. A step of 2 walks through the even numbers if you start on an even number. The stop is still excluded.

The step is 1 unless you write a third value, so only write it when the counter should jump.

Do not add 1 to the counter yourself. The Cambridge Python guide says the counter is "initialised and incremented by the looping construct": range already moves it. Changing the counter inside the loop does not change the next value range gives out.

for lap in range(1, 4):
    print(lap)
    lap = lap + 10

This still prints 1, 2, 3. The extra line does nothing useful, and in an exam it shows you have mixed up for and while.

05Worked example — Even steps up to but not including 8

Start at 0, stop before 8, step 2.

# Even numbers below 8
for step in range(0, 8, 2):
    print(step)

Output

0
2
4
6

What this does: 0, 2, 4 and 6 print. The next value would be 8, but 8 is the stop, so it is not printed. To include 8, the stop must be 9 or 10.

06Examiner tip — What a count-controlled answer needs
  1. A for line that ends with a colon, and a body indented four spaces.
  2. An inclusive end in the question means a stop one past that end.
  3. A step in the question goes third inside range.
  4. A total or counter is set to 0 before the loop and printed after it.

11Learn — Mistakes that lose the mark

The four range mistakes

Mistake What happens Fix
Stop equals the last number: range(1, 5) for 1 to 5 5 is never visited, so the answer is one step short Stop one past the end: range(1, 6)
total = 0 inside the loop It resets on every pass, so only the last value survives Put it before the for line
print(total) indented It prints on every pass Put it at the left edge, after the loop
Adding 1 to the counter inside the loop Does nothing to the next value, and shows for and while are mixed up Let range move the counter

Read a loop from the inside out. First list the values range will actually visit: include the start and exclude the stop. Then say what the indented lines do to each value. Then say which line runs after the loop. Candidates who start from the print and guess often include the stop value and end up one step high.

for or while? Use for when the number of passes is known before the loop starts. A while loop is for when you stop because a condition becomes false, not because a counter ran out.

On paper: end the for line with a colon and indent the body by a clear four-space gap. Name the counter after what it counts, such as lap or chair, unless the question gives you the name.

Tracing: write one row per visit, not one row per line of code. The stop value never gets a row. When the question asks for the output, write only the printed lines, in order.

14Learn — Before you leave the question

Check your answer against syllabus point 8.1.5(c) before you move on:

  • Header: does the for line end with a colon, and is the body indented four spaces?
  • Range: name the values it visits. Does the last one match the question's last number?
  • Totals: is the total set before the loop and printed after it?
  • Names and order: if the question gives a variable name, use it exactly. If it asks for output, write only the printed lines, in the order the program reaches them.

A value that is right in the middle of the program but wrong on the printed line is still a wrong answer.

15Close — You can repeat a known count

You can write a for loop with range, including a start and a step, and say exactly which values it visits.

Take to the exam:

  • the stop value is not included
  • a total is set to 0 before the loop
  • the final print is not indented inside the loop
