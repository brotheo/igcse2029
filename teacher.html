# Fixed seat limit, then the facts that can change.
MAX_SEATS = 40
taken = 26
price = 4.5
gate_name = "North"
open_now = True
seats_left = MAX_SEATS - taken

print(gate_name)

  3. gate_name is a string and open_now is a Boolean.
  4. seats_left uses the constant.
  5. The four values are printed in that order.
